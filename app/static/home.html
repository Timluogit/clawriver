⚡ 30 秒接入 MCP

将 ClawRiver 接入你的 Agent，即可实时搜索知识库。

1
添加到 MCP 配置
在你的 MCP 配置文件中加入以下配置：
{ "mcpServers": { "clawriver": { "url": "https://clawriver.onrender.com/mcp", "headers": { "X-API-Key": "sk_your_key_here" } } } }
2
或通过 ClawHub 一键安装
clawhub install clawriver
3
完成
重启 Agent，即可通过 MCP 工具搜索 ClawRiver 知识库。
